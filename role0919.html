3. 팀별 활동 때 이렇게 해주세요

팀에 들어가면 ‘선생님’이 아니라 퍼실리테이터입니다.
참여자에게 답을 알려주는 것이 아니라, 참여자가 직접 찾고 이야기하도록 질문해 주세요.

① 서비스 찾기

“어떤 서비스가 있는지 한번 찾아볼까요?”
“이것 말고 또 있을까요?”
“마스터플랜에서 직접 확인해볼게요.”
“이 서비스는 누구를 대상으로 한다고 되어 있나요?”

② 서비스 대상 확인

“우리에게 해당되는 서비스인지 어떻게 알 수 있을까요?”
“대상 부분을 한번 같이 볼까요?”
“이건 지금 우리가 판단하기보다 계획서에 적힌 내용을 먼저 확인해봅시다.”

③ ‘사용해봄 / 사용해보지 않음’ 분류

“이 서비스 실제로 이용해본 사람 있어요?”
“왜 이용해봤어요?”
“우리에게 있는데도 사용하지 않은 건 왜 그런 것 같아요?”
“정보를 몰랐던 건가요? 필요하지 않았던 건가요? 이용하기 어려운 점이 있었나요?”

④ ‘필요함 / 필요하지 않음’ 분류

“이 서비스가 우리에게도 필요하다고 생각해요?”
“어떤 상황에서 필요할까요?”
“왜 필요하다고 생각했어요?”
“다른 사람들도 비슷하게 필요할까요?”

⑤ 문제를 발견할 때

“그럼 여기에서 어떤 문제가 있다고 볼 수 있을까요?”
“서비스가 없는 게 문제인가요, 아니면 이용하기 어려운 게 문제인가요?”
“이걸 바꾼다면 어떻게 바꾸면 좋을까요?”

⑥ 직원이 피해야 할 말

  • “그건 이런 서비스예요.” → 먼저 참여자가 찾아보도록 하기
  • “그 서비스는 필요 없을 것 같은데?” → 판단하지 않기
  • “그냥 이렇게 쓰면 되잖아요.” → 참여자의 경험 먼저 듣기
  • “정책적으로는 이게 맞아요.” → 정답을 제시하지 않기

4. 김가을 — 기록 담당

무엇을 기록할까?
  1. 참여자가 무엇을 선택했는지
  2. 참여자가 어떤 의견을 냈는지
  3. 참여자들이 어떻게 의견을 조정했는지
  4. 서비스를 사용하지 않은 이유
  5. 우리에게 필요하다고 생각한 서비스와 이유
  6. 공동으로 선정된 문제·이슈
  7. 참여자가 제안한 개선 아이디어
  8. 정책제안 소그룹모임 참여 희망자 명단
기록할 때
“○○ 서비스가 있다는 것을 몰랐다는 의견이 나옴”처럼 누가 무엇을 했는지가 드러나게 기록합니다.
가능하면 참여자의 표현을 그대로 짧게 적어주세요.

5. 윤태권 — 사진 담당

사진은 ‘결과’보다 ‘과정’을 많이 남겨주세요.
  • 팀 구성 과정
  • 마스터플랜을 직접 찾아보는 모습
  • 서비스를 포스트잇에 작성하는 모습
  • 포스트잇을 분류하고 의견을 나누는 모습
  • 투표하는 모습
  • 공동 이슈와 개선안을 논의하는 모습
  • 요리 재료 손질·조리·역할 수행 모습
  • 완성된 음식
  • 참여자들이 함께 식사하는 모습
사진 촬영 팁
한 장의 완성된 결과물 사진만 찍기보다, 참여자가 직접 선택하고 움직이고 이야기하는 장면을 우선적으로 촬영합니다. 스터디 결과 보드가 완성되면 전체가 보이도록 사진을 남깁니다.

상황김가을윤태권

7. 두 직원이 공통으로 기억할 것

  1. 참여자가 먼저 생각하고 말할 시간을 주세요.
  2. 직원이 답을 정하지 않습니다.
  3. 참여자의 의견이 서로 다를 경우 한쪽으로 결론을 몰지 않습니다.
  4. “왜?”만 반복하기보다 “어떤 상황에서?”, “어떻게 바뀌면 좋을까?”로 구체화합니다.
  5. 개인 문제보다 서비스와 지원체계에서 어떤 어려움이 있었는지 살펴봅니다.
  6. 안전과 관련된 상황에서는 즉시 개입합니다.
